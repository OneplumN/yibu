# 桌面版审核问题修复

日期：2026-10-22。范围：Tauri 桌面版、SQLite、桌面开发快照及共享业务逻辑。
本记录对应 `2026-10-22-claude-verification.md` 中核实的问题。
Web 专属初始化竞态、浏览器兼容性与 Web 端验收不在本轮范围。

## 已修改

1. 导入：校验各实体字段、日期、重复 ID、任务与项目引用、焦点与任务引用。
   校验失败不写库。兼容旧 v1 备份省略 priority、notes 的情况。
2. 原子替换：Rust 从 Tauri SQL 插件状态复用 SQLite pool，在一个连接、一个事务内
   替换全部备份数据。任何中途错误都 rollback，不使用递归恢复备份。
3. 焦点列表：事务内校验旧列表后替换，失败保留原列表；加入、移出、重排顺序执行。
4. 任务并发：同一任务的修改排队；执行前读取已保存数据，用单条带旧 payload 条件的
   UPDATE 检测冲突。冲突后重新读取并重试，避免旧窗口覆盖新字段。
5. 项目并发：修改和排序排队；存储事务比较旧数据后更新，排序整批提交。
6. 删除项目：项目、关联任务与焦点在同一事务中删除。
7. 导出：读取全部数据使用一致的数据库读事务，避免混用不同时间点的列表。
8. 备份密钥：默认备份和开发快照不包含 API 密钥；恢复到同一设备时，只在配置 ID
   和 endpoint 都一致的情况下保留本机密钥。完整内部导出需显式 includeSecrets。
9. 桌面开发启动：SQLite 为主数据源，不自动导入旧 Vite JSON 快照。
10. 开发快照：前端写入排队、检查 HTTP 错误；服务端临时文件写入后原子 rename，
    请求串行，文件权限 0600。可通过专用环境变量隔离验收快照路径。
11. AI：桌面统一原生 HTTP，120 秒超时。切换配置、离开设置或关闭报告弹窗时取消
    对应原生请求；取消前已登记 ID，避免取消早于请求启动的竞态。
12. 故障恢复：渲染错误显示重新加载入口；桌面记录固定错误类别和时间，限制日志大小。
    日志不记录密钥、请求头、提示词、任务内容或备份正文。
13. CI：增加 macOS 原生 SQLite/网络测试 job。尚未推送或执行远端 workflow。

共享存储接口的非桌面实现只做契约兼容，业务单元测试继续用隔离测试库运行。
未引入数据库 schema 迁移、付费服务或新安装包。
